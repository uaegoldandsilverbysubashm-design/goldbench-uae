# Security Policy

## Supported Versions

GoldBench UAE is a single static web page that is deployed continuously. Only the latest version, the one on the `main` branch and live at https://goldbenchuae.vercel.app, is supported with fixes.

| Version                | Supported          |
| ---------------------- | ------------------ |
| Latest (`main`)        | :white_check_mark: |
| Older commits / copies | :x:                |

## Reporting a Vulnerability

If you find a security issue, please report it privately. Do not open a public issue.

- **Preferred:** use GitHub's **Report a vulnerability** button under this repository's **Security** tab.
- **Email:** uaegoldandsilverbysubashm@gmail.com

Please include a short description of the issue, the steps to reproduce it, and the browser or device you used.

**What to expect**
- An acknowledgement within 3 business days.
- An update at least every 7 days until the issue is resolved.
- If the report is accepted, a fix is deployed as soon as possible and you are credited if you wish. If it is declined, you will get a short explanation.

## Scope and Notes

- This is an educational and research project. It is a client-side tool that displays indicative gold, silver and platinum rates, and it stores no user accounts or personal data.
- Rates are for reference only and are not financial advice.
- Third-party data providers (Swissquote, gold-api.com and Alpha Vantage) are outside this project's control. Please report issues with them to the providers directly.
